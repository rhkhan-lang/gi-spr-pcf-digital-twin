# Publication disclosure note

Use the digital twin in the paper as a physics-guided interactive demonstrator unless a FEM-trained surrogate has been generated and independently validated.

Recommended wording:

> The browser-based digital twin is used as an interactive implementation layer for visualizing the geometry, core/SPP field localization, RI-pair response, inverse-design variables and fabrication-tolerance behavior. The current surrogate interface is a demonstration model and does not replace full FEM verification.

Do not report the demo R², active-learning curves, or inverse-design convergence as validated scientific performance unless they are regenerated from real FEM training logs and held-out FEM test cases.
